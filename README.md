**C#** and **WPF (.NET)**
This project is designed to provide a fast and efficient way to organize and manage personal notes with a clean user interface.

## Features
- **Modern UI:** Built using WPF layout and styling components.
- **Note Management:** Create, edit, and organize notes into sections.
- **Performance Optimized:** Includes background optimizations for handling text data efficiently.
- **Easy Configuration:** Simple setup with options for logging and data export.

## Technologies Used
- C# / .NET
- WPF (Windows Presentation Foundation)
- JSON for configuration and local storage
